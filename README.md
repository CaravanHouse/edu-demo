# Zukko Academy — демо-сайт учебного центра

Демо от [CaravanHouse](https://caravanhouse.uz): сайт вымышленного учебного центра в Ташкенте.
Живая версия: https://edu.caravanhouse.uz

Что показывает демо:
- **Курсы**: фильтры по направлению (английский, IT, школьникам, экзамены) и формату, свободные места, старт группы, преподаватель, цена в месяц.
- **Тест уровня английского**: 6 вопросов → уровень CEFR и рекомендованный курс, сразу запись на пробный урок.
- **Расписание групп** на неделю с фильтром по направлению; нажатие на занятие открывает запись в эту группу.
- **Запись на пробный урок**: курс, группа, «для себя / для ребёнка», контакты.
- **Личный кабинет ученика** (`/ru/cabinet`): прогресс по курсам, посещаемость, следующее занятие, домашние задания со статусами и оценками, оплаты.
- Русский и узбекский (`/ru`, `/uz`), адаптивная вёрстка.

## Персональные демо для центров

По ссылке `https://edu.caravanhouse.uz/<язык>/p/<slug>` сайт показывает демо конкретного центра:
- его название, логотип (или инициалы), фирменный цвет, телефон и курсы;
- плашку «Демо от CaravanHouse IT» и кнопку «Хочу такое для своего центра» — она ведёт в бота заявок с меткой `demo_<slug>`.

О центре ничего не выдумывается: у курсов вместо цен и сроков подпись «здесь будет описание курса», блок преподавателей скрыт, расписание помечено как пример.

**Где лежат конфиги.** В этом публичном репозитории их нет:
- исходники хранятся в приватном репозитории `CaravanHouse/sales`;
- оттуда скрипт загружает копию в приватное хранилище Vercel Blob проекта (`edu/<slug>/config.json` и логотип).

Сайт читает конфиги по токену `BLOB_READ_WRITE_TOKEN` (`lib/prospect.ts`).

Персональные страницы и `/api` отдаются с `noindex, nofollow` (мета-тег и заголовок `X-Robots-Tag`) и в sitemap не попадают. Страницы рендерятся на каждый запрос, конфиг подхватывается сразу после загрузки скриптом (API кешируется на 5 минут).

`/api/p/<slug>` — тот же конфиг в JSON для демо-бота записи на пробный урок.

Это демо: учебный центр, преподаватели и цифры придуманы, заявки никуда не отправляются, кабинет показан на демо-данных. В настоящем проекте здесь вход учеников, база групп и платежей, уведомления в Telegram.

Стек: Next.js 16, React 19, TypeScript, Tailwind CSS 4. Хостинг — Vercel.

```bash
npm install
npm run dev   # http://localhost:3000
```
